# Products and Orders SQL Project

This project demonstrates SQL queries using PostgreSQL and pgAdmin 4.

### Topics Covered
- One-to-Many Relationship
- Primary Key and Foreign Key
- INNER JOIN and LEFT JOIN
- WHERE and ORDER BY
- COUNT() and SUM()
- GROUP BY and HAVING
- DISTINCT

### Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

### Project Objective
To analyze product and order data using SQL queries and understand relationships between database tables.

### Queries
This project includes 8 SQL questions based on Products and Orders data.
